# En・Base 自社ホームページ 設計仕様書

- 日付: 2026-09-21
- 対象: `ホームページ作成/自社ホームページ/`

## 目的・背景

屋号「En・Base」の自社ホームページを新規作成する。事業内容はAI活用支援（業務効率化コンサル、AIアプリ作成、ツール導入支援、社内AI活用ロードマップ策定）。想定読者は中小企業の経営者全般。スタートアップフェーズのため、コンバージョン獲得・信頼構築・サービス説明のバランスを取る方針。

「DX」という表記は使わない（AI活用支援として訴求する）。

## ブランド要素

- 屋号: **En・Base**
- ロゴ: `ロゴ.png`（既存ファイル、`images/` へ移動して使用）
- 配色: ロゴ準拠— 青グラデーション（キーカラー）、黒（文字）、ゴールド（差し色・少量のアクセント）、白背景中心
- トーン: 清潔感のあるテック系スタートアップ

## ページ構成

1ページ完結のLP形式 + 無料診断は別ページの2階層構成。

```
自社ホームページ/
├── index.html              # トップページ
├── css/style.css
├── js/main.js               # スムーススクロール等の軽量なUI制御
├── images/ロゴ.png
├── shindan/
│   ├── index.html            # 診断ツール本体（En・Baseブランドでラップ）
│   ├── css/ 、 js/            # 診断ロジック（フェーズ0〜5判定）を移植
└── CLAUDE.md
```

### トップページ（index.html）セクション

| # | セクション | 内容方針 |
|---|---|---|
| 1 | ヒーロー | En・Baseロゴ＋キャッチコピー（AI活用支援、「DX」表記なし）＋「無料診断」「お問い合わせ」CTA |
| 2 | 事業内容 | 4カード：①業務効率化コンサル ②AIアプリ作成 ③ツール導入支援（Claude Code等） ④社内AI活用ロードマップ策定 |
| 3 | 選ばれる理由/強み | 「一社ごとのお困りごとにフォーカスし、テンプレ的な提案ではなくオーダーメイドで解決する」を軸に、専門用語なし・伴走型・実務実績（不動産業界支援等）を訴求 |
| 4 | 実績・事例 | 名刺・X投稿・既存実績から2〜3件ピックアップ。具体的な文言は実装時にユーザーと確定 |
| 5 | 無料AI診断への導線 | フェーズ0〜5フレームワークの簡単な説明＋「診断してみる」ボタン→`shindan/`へ遷移 |
| 6 | 会社概要 | 屋号・代表者名・連絡先等（詳細は実装時に確定） |
| 7 | お問い合わせ | Googleフォーム埋め込み（下記参照） |

### 無料診断ページ（shindan/index.html）

既存の `診断ツール/index.html`（AI活用診断ツール、フェーズ0〜5フレームワーク、`LEVELS` 配列が判定ロジックの正）をベースにコピーし、En・Baseのヘッダー・フッター・配色でラップする。診断ロジック自体は変更しない。

トップページとの回遊性を持たせるため、診断結果画面から「お問い合わせ」への導線も設置する。

## お問い合わせフォーム

Googleフォームをiframe埋め込みする。フォームはユーザー側が別途作成する（項目例：お名前・会社名・連絡先・相談内容）。フォーム未作成の間はプレースホルダー枠を表示し、URL共有後に差し替える。

## 技術構成

- 静的HTML/CSS/JS一式。サーバー・ビルドツール不要
- レスポンシブ対応（モバイル・PC両対応）
- 外部依存はGoogleフォームのiframe埋め込みのみ

## コンテンツソース

- 名刺情報、X投稿、既存の実績（不動産業界向けAI/DX支援など）を「実績・事例」「会社概要」セクションに反映。具体的な文言・素材は実装フェーズでユーザーと確定する。

## スコープ外

- CMS・ブログ機能
- 多言語対応
- サーバーサイド処理（フォーム送信含む、Googleフォームに委譲）
- 診断ツール本体のロジック改修（フレームワークは既存のものをそのまま使用）
